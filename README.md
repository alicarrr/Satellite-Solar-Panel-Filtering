# Satellite-Solar-Panel-Filtering
Author: Alison Carr

This repo includes all code developed for my undergraduate thesis  at the University of Sydney titled ``Optimisation of Spectral Filtering for In-Orbit Spacecraft Thermal Control''.

_Note: the `simulation_data.pkl` file within this repo is outdated, as the final data for the thesis was too large to upload. To regenerate the full pickle file, run the `run.sh` file from the repository._
